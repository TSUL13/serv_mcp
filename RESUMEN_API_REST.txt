📅 Fecha: 3 de febrero de 2026
🎯 Objetivo: Hacer que GPT y Gemini puedan consultar tu red SD-WAN

================================================================================
  ❌ EL PROBLEMA
================================================================================

MCP (Model Context Protocol) SOLO funciona con Claude Desktop.

❌ GPT no entiende MCP
❌ Gemini no entiende MCP  
❌ Otras IAs no entienden MCP

MCP es un protocolo propietario de Anthropic (creadores de Claude).

================================================================================
  ✅ LA SOLUCIÓN
================================================================================

CREAR UNA API REST

API REST = Lenguaje universal que todas las IAs entienden

  🤖 CONFIGURAR GPT-4 (ChatGPT Plus)

Requisito: Tener ChatGPT Plus o Enterprise

1. Ve a: https://chat.openai.com/gpts/editor

2. Crea un nuevo GPT:
   - Nombre: "SD-WAN Network Assistant"
   - Description: "Asistente para gestión de redes Cisco SD-WAN"

3. En "Configure" → "Actions":
   - Click "Create new action"
   - Importa el schema desde: http://localhost:8000/openapi.json
   
   O copia manualmente el schema OpenAPI (ver CONECTAR_GPT_GEMINI.md)

4. Instructions:
   
   "Eres un experto en redes Cisco SD-WAN. Tienes acceso a una API
   para consultar dispositivos, sesiones BFD, alarmas y más.
   Responde preguntas sobre la red usando las herramientas disponibles."

5. Guarda y prueba:
   
   Usuario: "¿Cuántos dispositivos hay en la red?"
   GPT: [Llama a GET /devices] "Hay 332 dispositivos, 327 operativos"

NOTA: Si tu API está en localhost, GPT no puede acceder directamente.
      Opciones:
      a) Exponer con ngrok: ngrok http 8000
      b) Deploy en servidor con IP pública
      c) Usar Cloudflare Tunnel

================================================================================
  🤖 CONFIGURAR GEMINI (Google AI)
================================================================================

Usa Function Calling de Gemini API:

```python
import google.generativeai as genai
import requests

genai.configure(api_key="TU_API_KEY")

# Definir funciones
functions = [{
    "name": "list_devices",
    "description": "Lista dispositivos SD-WAN",
    "parameters": {"type": "object", "properties": {}}
}]

# Crear modelo con funciones
model = genai.GenerativeModel(
    model_name='gemini-1.5-pro',
    tools=functions
)

# Usar
chat = model.start_chat()
response = chat.send_message("¿Cuántos dispositivos hay?")

# Si Gemini llama a la función, ejecuta tu API
if response.candidates[0].content.parts[0].function_call:
    result = requests.get("http://localhost:8000/devices").json()
    # Enviar resultado de vuelta a Gemini...
```

================================================================================
  🔐 SEGURIDAD (IMPORTANTE)
================================================================================

⚠️  LA API ACTUAL NO TIENE AUTENTICACIÓN

Cualquiera que acceda a http://localhost:8000 puede consultar tu red.

PARA PRODUCCIÓN, AGREGA:

1. Autenticación (Bearer Token):
   
   from fastapi import Security
   from fastapi.security import HTTPBearer
   
   security = HTTPBearer()
   
   @app.get("/devices", dependencies=[Depends(verify_token)])
   def list_devices():
       # ...

2. Rate Limiting:
   
   pip install slowapi
   # Limitar requests por IP

3. HTTPS:
   
   uvicorn api_rest:app --ssl-keyfile key.pem --ssl-certfile cert.pem

4. Firewall:
   
   # Solo permitir IPs conocidas
   iptables -A INPUT -p tcp --dport 8000 -s 192.168.1.0/24 -j ACCEPT

Ver detalles en: CONECTAR_GPT_GEMINI.md sección "Seguridad"

================================================================================
  🌍 EXPONER A INTERNET (OPCIONAL)
================================================================================

Para que GPT pueda acceder (está en la nube de OpenAI):

OPCIÓN A: ngrok (MÁS FÁCIL)
   
   # Instalar
   sudo apt install ngrok
   
   # Autenticar
   ngrok config add-authtoken TU_TOKEN
   
   # Exponer
   ngrok http 8000
   
   # Recibirás: https://abc123.ngrok.io
   # Usa esta URL en GPT Custom Actions

OPCIÓN B: Cloudflare Tunnel
   
   cloudflared tunnel --url http://localhost:8000

OPCIÓN C: VPS (Producción)
   
   - Deploy en AWS / Google Cloud / DigitalOcean
   - Instala API en servidor con IP pública
   - Configura dominio, SSL, firewall

================================================================================
  📚 ENDPOINTS DISPONIBLES
================================================================================

GET /                          - Información de la API
GET /devices                   - Lista todos los dispositivos
GET /devices/{id}/health       - Salud de dispositivo
GET /devices/{id}/bfd          - Sesiones BFD de dispositivo
GET /devices/{id}/cpu-memory   - Uso de CPU y memoria
GET /devices/{id}/interfaces   - Estadísticas de interfaces
GET /devices/{id}/omp-tunnels  - Túneles OMP
GET /devices/{id}/diagnostic   - Diagnóstico completo
GET /alarms/critical           - Alarmas críticas
GET /control-connections       - Conexiones de control
GET /network-summary           - Resumen de red
GET /bfd/total                 - Total sesiones BFD (con muestreo)
GET /applications/top          - Top aplicaciones
GET /search                    - Buscar dispositivos (query params)
GET /sites/{id}/devices        - Dispositivos por sitio
GET /security/events           - Eventos de seguridad

Documentación completa: http://localhost:8000/docs

¿QUÉ HICIMOS?
   
   Creamos una API REST que convierte las 15 funciones del servidor MCP
   en endpoints HTTP estándar, accesibles por cualquier IA o cliente.

¿POR QUÉ?
   
   Porque GPT y Gemini NO soportan MCP (protocolo de Anthropic/Claude).
   Necesitan HTTP/JSON estándar.

¿CÓMO FUNCIONA?
   
   IA → HTTP Request → api_rest.py → vManage API → Response → IA

¿QUÉ ARCHIVOS?
   
   - api_rest.py (servidor FastAPI)
