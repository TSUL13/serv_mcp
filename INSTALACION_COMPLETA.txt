  2️⃣ INSTALACIÓN DE PYTHON Y DEPENDENCIAS
================================================================================

PASO 2.1: Verificar Python
--------------------------
Abre una terminal y ejecuta:

    python3 --version

Debe mostrar Python 3.8 o superior (recomendado 3.10+)

Si no tienes Python instalado:

    # En Ubuntu/Debian:
    sudo apt update
    sudo apt install python3 python3-pip python3-venv

    # En macOS (con Homebrew):
    brew install python3

    # En Windows:
    # Descarga desde https://www.python.org/downloads/


PASO 2.2: Clonar o descargar el proyecto
---------------------------------------
Si tienes git:

    cd ~/Documentos
    git clone <url-del-repositorio> serv_mcp
    cd serv_mcp

Si no tienes git, descarga los archivos manualmente a:
    ~/Documentos/serv_mcp/


PASO 2.3: Crear entorno virtual
------------------------------
Dentro del directorio del proyecto:

    cd ~/Documentos/serv_mcp
    python3 -m venv venv

Esto crea un entorno aislado para las dependencias.


PASO 2.4: Activar entorno virtual
--------------------------------
Cada vez que trabajes con el proyecto, activa el entorno:

    source venv/bin/activate

Tu prompt cambiará a mostrar: (venv)

Para desactivar después:

    deactivate


PASO 2.5: Instalar dependencias
------------------------------
Con el entorno activado:

    pip install fastmcp requests urllib3 python-dotenv browser-cookie3

Esto instala:
  - fastmcp: Framework para servidor MCP
  - requests: Cliente HTTP para API de vManage
  - urllib3: Gestión de conexiones
  - python-dotenv: Manejo de variables de entorno
  - browser-cookie3: Extracción de cookies del navegador

PASO 3.3: Verificar instalación

Abre Claude Desktop y verifica que funciona correctamente.

  5️⃣ CONFIGURACIÓN DEL SERVIDOR MCP
================================================================================

PASO 5.1: Configurar credenciales
--------------------------------
Navega al directorio del proyecto:

    cd ~/Documentos/serv_mcp

Edita el archivo .env:

    nano .env

O si no existe, créalo:

    cat > .env << 'EOF'
# Configuración de acceso a Cisco SD-WAN vManage
# IMPORTANTE: Usar minúsculas en el dominio

# IP o hostname del vManage (sin https://)
VMANAGE_IP=vmanage.cjf.gob.mx

# Credenciales de autenticación (no se usan pero deben estar)
VMANAGE_USERNAME=tu_usuario
VMANAGE_PASSWORD=tu_contraseña
EOF

Guarda el archivo (Ctrl+O, Enter, Ctrl+X en nano)

IMPORTANTE:
  - El dominio debe estar en minúsculas: vmanage.cjf.gob.mx
  - Las credenciales son informativas, el sistema usa cookies


PASO 5.2: Configurar Claude Desktop
----------------------------------
Crea el directorio de configuración:

    mkdir -p ~/.config/Claude

Edita o crea el archivo de configuración:

    nano ~/.config/Claude/claude_desktop_config.json

Pega este contenido (ajusta las rutas según tu instalación):

{
  "globalShortcut": "Ctrl+Space",
  "mcpServers": {
    "cisco-sdwan": {
      "command": "/home/TU_USUARIO/Documentos/serv_mcp/venv/bin/python",
      "args": [
        "/home/TU_USUARIO/Documentos/serv_mcp/server.py"
      ],
      "env": {}
    }
  }
}

REEMPLAZA "TU_USUARIO" con tu nombre de usuario real.

Para obtener tu usuario:

    echo $USER

Para obtener la ruta completa:

    echo "$HOME/Documentos/serv_mcp/venv/bin/python"

Guarda el archivo.


PASO 5.3: Dar permisos de ejecución
----------------------------------
Asegúrate de que los scripts tengan permisos:

    cd ~/Documentos/serv_mcp
    chmod +x server.py
    chmod +x cli.py
    chmod +x browser_cookies.py
    chmod +x test_completo.py
    chmod +x verificar_claude_desktop.py

================================================================================
  8️⃣ SOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA: "No se encontraron cookies"
------------------------------------
CAUSA: Navegador no abierto o sin sesión activa

SOLUCIÓN:
  1. Abre Chrome, Firefox o Edge
  2. Ve a https://vmanage.cjf.gob.mx
  3. Inicia sesión
  4. Deja la pestaña abierta
  5. Ejecuta: python browser_cookies.py


PROBLEMA: "Las herramientas no aparecen en Claude Desktop"
---------------------------------------------------------
CAUSA: Configuración incorrecta o rutas erróneas

SOLUCIÓN:
  1. Verifica ~/.config/Claude/claude_desktop_config.json
  2. Asegúrate de que las rutas sean absolutas y correctas
  3. Ejecuta: ls -la ~/Documentos/serv_mcp/venv/bin/python
  4. Cierra y abre Claude Desktop
  5. Revisa logs: tail -f ~/.config/Claude/logs/*


PROBLEMA: "Error al ejecutar herramienta"
----------------------------------------
CAUSA: Sesión expiró o cookies inválidas

SOLUCIÓN:
  1. Refresca la página de vManage en el navegador
  2. Si pide login, inicia sesión nuevamente
  3. Ejecuta: python test_completo.py
  4. Reintenta en Claude Desktop


PROBLEMA: "HTTP 401 Unauthorized"
--------------------------------
CAUSA: Cookies expiradas

SOLUCIÓN:
  1. Verifica sesión en navegador
  2. Cierra y abre el navegador
  3. Inicia sesión nuevamente
  4. Ejecuta: python browser_cookies.py


PROBLEMA: "ModuleNotFoundError"
------------------------------
CAUSA: Dependencias no instaladas o entorno no activado

SOLUCIÓN:
  1. Activa el entorno: source venv/bin/activate
  2. Instala dependencias: pip install -r requirements.txt
  3. O manualmente: pip install fastmcp requests urllib3 python-dotenv browser-cookie3


PROBLEMA: "Permission denied" al ejecutar scripts
------------------------------------------------
CAUSA: Falta permisos de ejecución

SOLUCIÓN:
  chmod +x *.py


PROBLEMA: Claude Desktop no inicia el servidor MCP
-------------------------------------------------
CAUSA: Rutas incorrectas en configuración

SOLUCIÓN:
  1. Obtén ruta absoluta:
     readlink -f ~/Documentos/serv_mcp/venv/bin/python
  2. Actualiza claude_desktop_config.json con esa ruta
  3. Reinicia Claude Desktop


PROBLEMA: "Browser not found" o error con navegador
--------------------------------------------------
CAUSA: browser-cookie3 no encuentra el navegador

SOLUCIÓN ALTERNATIVA:
  1. Usa el sistema manual de cookies
  2. Abre Firefox Inspector (F12)
  3. Ve a Network > Headers
  4. Copia JSESSIONID y XSRF-TOKEN
  5. Ejecuta: python test_con_cookies.py
  6. Pega las cookies cuando se solicite

================================================================================
  📝 NOTAS IMPORTANTES
================================================================================

1. El sistema usa COOKIES del navegador, NO autenticación programática
   - Esto es porque vManage bloquea scripts
   - Por eso DEBES mantener el navegador abierto

2. Las cookies se extraen automáticamente:
   - No necesitas copiar/pegar manualmente
   - El sistema refresca cookies cuando expiran
   - Todo es automático y transparente

3. Seguridad:
   - Las cookies solo existen en memoria
   - No se almacenan en archivos
   - Se extraen en tiempo real del navegador

4. Compatibilidad:
   - Solo funciona con Chrome, Firefox o Edge
   - El dominio DEBE estar en minúsculas en .env
   - Python 3.8+ requerido

5. Soporte:
   - Usa python verificar_claude_desktop.py para diagnóstico
   - Los logs de Claude están en ~/.config/Claude/logs/
   - Ejecuta test_completo.py para verificar conexión
