FLUJO DE DATOS: GPT → vManage
══════════════════════════════

1. Usuario en ChatGPT:
   "¿Cuántos dispositivos hay caídos?"
   
2. GPT decide usar función:
   list_devices()
   
3. GPT hace HTTP Request:
   GET http://localhost:8000/devices
   
4. api_rest.py recibe:
   - Extrae cookies con browser_cookies.py
   - Autentica con vManage
   
5. vManage responde:
   {"total": 332, "devices": [...]}
   
6. api_rest.py devuelve:
   JSON al cliente
   
7. GPT procesa y responde:
   "Hay 332 dispositivos, 5 están caídos"


FLUJO DE DATOS: Claude Desktop → vManage
═════════════════════════════════════════

1. Usuario en Claude Desktop:
   "¿Cuántos dispositivos hay caídos?"
   
2. Claude decide usar tool:
   listar_dispositivos
   
3. Claude comunica con MCP:
   stdio → server.py
   
4. server.py ejecuta:
   - Extrae cookies con browser_cookies.py
   - Autentica con vManage
   
5. vManage responde:
   {"data": [...]}
   
6. server.py devuelve:
   Via MCP a Claude
   
7. Claude procesa y responde:
   "Hay 332 dispositivos, 5 están caídos"

CUÁNDO USAR CADA UNO
═════════════════════

USA MCP (server.py) CUANDO:
───────────────────────────
✅ Trabajas exclusivamente con Claude Desktop
✅ Quieres integración nativa y fluida
✅ No necesitas acceso desde otros clientes
✅ Valoras simplicidad de setup


USA API REST (api_rest.py) CUANDO:
───────────────────────────────────
✅ Necesitas GPT o Gemini
✅ Quieres acceso desde navegador/Postman
✅ Múltiples clientes consumirán la API
✅ Necesitas documentación automática
✅ Scripts y automatización
✅ Integración con sistemas externos


USA AMBOS CUANDO:
─────────────────
✅ Equipo usa diferentes IAs (Claude + GPT)
✅ Necesitas máxima flexibilidad
✅ Producción requiere API estándar
✅ Desarrollo usa Claude Desktop

COSTO: Mínimo (comparten browser_cookies.py)
BENEFICIO: Máximo (mejor de ambos mundos)


EJEMPLO: PREGUNTA SIMPLE
═════════════════════════

Pregunta: "¿Cuántos dispositivos hay?"


CON MCP (Claude Desktop):
────────────────────────

  Claude Desktop
       ↓ (MCP - stdio)
  server.py
       ↓ (cookies)
  vManage API
       ↓ (JSON)
  {"data": [332 dispositivos]}
       ↑
  Claude: "Hay 332 dispositivos"

  Tiempo: ~2 segundos
  Líneas de log: 3-4


CON API REST (GPT/Gemini):
──────────────────────────

  ChatGPT / Gemini
       ↓ (HTTP GET)
  GET localhost:8000/devices
       ↓ (cookies)
  api_rest.py → vManage API
       ↓ (JSON)
  {"total": 332, "devices": [...]}
       ↑ (HTTP 200)
  GPT: "Hay 332 dispositivos"

  Tiempo: ~2-3 segundos
  Líneas de log: 5-6
  Visible en: /docs


EJEMPLO: DIAGNÓSTICO COMPLETO
══════════════════════════════

Pregunta: "Dame un diagnóstico completo del router 10.1.1.1"


CON MCP:
────────

Claude llama a 4 tools en paralelo:
  - ver_salud_equipo(10.1.1.1)
  - ver_sesiones_bfd(10.1.1.1)
  - ver_estadisticas_interfaces(10.1.1.1)
  - ver_uso_cpu_memoria(10.1.1.1)

Resultado: Análisis completo en 3-4 segundos


CON API REST:
─────────────

GPT llama a 1 endpoint especializado:
  GET /devices/10.1.1.1/diagnostic

Que internamente hace las 4 consultas

Resultado: Análisis completo en 3-4 segundos


VENTAJA API REST: Un solo endpoint hace todo
VENTAJA MCP: Herramientas específicas más flexibles
