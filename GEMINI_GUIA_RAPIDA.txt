================================================================================
  📝 CÓDIGO MÍNIMO
================================================================================

Este es el código mínimo para consultar con Gemini:

```python
import google.generativeai as genai
import requests

# Configurar
genai.configure(api_key="TU_API_KEY")

# Definir función
functions = [{
    "name": "listar_dispositivos",
    "description": "Lista dispositivos SD-WAN",
    "parameters": {"type": "object", "properties": {}}
}]

# Crear modelo
model = genai.GenerativeModel(
    model_name='gemini-1.5-pro',
    tools=functions
)

# Preguntar
chat = model.start_chat()
response = chat.send_message("¿Cuántos dispositivos hay?")

# Si llama a función
if response.candidates[0].content.parts[0].function_call:
    # Ejecutar API
    data = requests.get("http://localhost:8000/devices").json()
    
    # Devolver resultado
    response = chat.send_message(
        genai.protos.Content(
            parts=[genai.protos.Part(
                function_response=genai.protos.FunctionResponse(
                    name="listar_dispositivos",
                    response={"result": data}
                )
            )]
        )
    )

print(response.text)
```
